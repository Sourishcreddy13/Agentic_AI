## Application Entry Points

### Mandatory

```bash
python cli.py
```

### Optional Good-to-Have UI

```bash
streamlit run app.py
```

The CLI is the required single-command application path. Streamlit is a
visual interface and does not replace the CLI requirement.

## Regenerating Evidence

Every artifact cited above is regenerated by running the corresponding
test(s) or `python cli.py` — none of it is hand-edited.
`tests/test_evidence_artifacts.py` additionally asserts that the committed
artifacts contain no API key, no raw email address, and no unredacted
applicant identifier.
